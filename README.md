# さんちゅ

同じ授業を受けている学生どうしで、課題・授業の連絡・掲示板を共有するアプリのプロトタイプです。学内通貨「ぺい」でお礼を送り合えます。

## 動かし方

```bash
npm install
npm run dev
```

ログイン画面の下にある「デモの学生として試す」から入ると、デモ用のデータが入った状態で試せます。
データはブラウザ（localStorage）に保存されます。「マイページ → 設定 → デモデータを初期化」で最初の状態に戻せます。

### 時間割スクショの読み取り（Claude API）

UNIPA の時間割画面のスクショは、サーバー側（`api/parse-timetable.ts`）で Claude に読み取らせます。
使うには、環境変数 `ANTHROPIC_API_KEY` を設定します。

```bash
ANTHROPIC_API_KEY=sk-ant-... npm run dev
```

キーがなくても、読み取り画面の「デモ用のサンプル結果を使う」で、その後の流れは試せます。

### デモ用の操作（設定画面）

- **デモ用の時計**：「授業中の連絡」は授業時間中しか投稿できないので、時計をずらして試せます
- **別の学生に切り替える**：依頼を引き受ける側や、送金を受け取る側を試せます

## Vercel へのデプロイ

1. GitHub に push する
2. https://vercel.com/new でリポジトリを Import する（設定は `vercel.json` に書いてあるので、そのまま Deploy で OK）
3. Project → Settings → Environment Variables に `ANTHROPIC_API_KEY` を追加し、Redeploy する

`vercel.json` の中身:

- 画面は `vite build` で作った `dist/` を静的に配信。`/timetable` などのページを直接開いても表示されるよう、`/api/` 以外は `index.html` に回す
- `api/parse-timetable.ts` は Vercel Functions（Node.js 22）。読み取りに時間がかかることがあるので、実行時間の上限を 60 秒にしている

Vercel の関数は `api/` 内のファイル同士の import が解決できないことがあるため、読み取り処理は `api/parse-timetable.ts` の 1 ファイルにまとめています。開発サーバー（`vite.config.ts`）も同じ関数を呼びます。

> **API の利用料金に注意**：`/api/parse-timetable` は誰でも呼べます（ログインの仕組みがまだモックのため）。
> URL を公開する前に、Anthropic Console で API キーの利用上限（spend limit）を設定してください。

## 機能

| 画面 | できること |
|---|---|
| ログイン | LINE 連携（モック）→ 学籍番号を登録 → 口座開設（ボーナス 1,000 ぺい） |
| ホーム | ぺい残高と送金ボタン、いまの授業と今日の連絡、未提出課題（締め切り順）、履修中の授業の掲示板をまとめた一覧 |
| 時間割 | UNIPA 風の表。スクショで一括登録（さんちゅに無い授業は新しく作成）、空きコマから手で追加 |
| 授業 | 今日の連絡、掲示板、共有された課題と提出率、履修者一覧、シラバスのリンクと埋め込み |
| 課題 | 登録（同じ授業で締め切りが近い課題があれば被りを確認）、提出率、提出済みにするだけ／注意書き・所要時間・成果物の共有、引き受けた依頼 |
| 依頼板 | 質問・解説／勉強会／チューターの依頼。即決価格、掲載時間、希望期限（課題から選ぶと締め切りの1時間前が既定）、価格順・期限順の並び替え、成立すると双方に LINE 追加・送金の案内 |
| ぺい | 学籍番号で相手を探して送金、月ごとの収支グラフ、何で稼いで何に使ったか、前の月への移動とカレンダー（今月に戻るボタン付き） |
| マイページ | アイコン変更、プロフィール（就活で聞かれそうな項目・人生史）、プロフカードと名刺を PDF／画像で保存 |
| 受信ボックス | アプリ内通知、ブラウザ通知のオン |

アイコンはどこでもタップすると、その人のプロフィールに移動します。

### 通知

- 自分以外の履修者全員、または履修者の 9 割が提出していて、自分が未提出のとき
- 締め切りの 1 時間前に未提出のとき
- 授業中の連絡（休講・教室変更など）が共有されたとき
- 依頼が成立したとき、ぺいを受け取ったとき

## 元の案から変えたところ

大学の不正行為や法律にあたる使い方になる機能は、形を変えています。

| 元の案 | このアプリでの形 |
|---|---|
| 出席コードの共有 | 授業中の連絡（休講・教室変更・遅れ・配布物）。「確認」が多い連絡が上に出る |
| 課題の代行の求人 | 依頼板（質問・解説、勉強会、チューター）。代行や答えの受け渡しにあたる言葉は投稿時に弾く |
| 提出物の共有 | 注意書きと所要時間はすぐ公開。成果物（文章・ファイル）は締め切り後に公開 |
| 現金とぺいの両替 | 作らない。ぺいは現金と交換できないお礼用のポイント |

## 荒らし対策（民度が低い前提）

| 想定する行為 | 対策 |
|---|---|
| 悪口・個人情報・代行・出席コード・現金取引・勧誘の書き込み | 投稿前に弾く（[src/lib/moderation.ts](src/lib/moderation.ts)）。全角半角・カタカナ・間の空白や記号・伸ばし棒・繰り返しをそろえてから判定するので「代 行」「ダイコウ」もすり抜けない |
| 連投・同じ内容の繰り返し | 1分3件・1日40件まで、直前と同じ内容は不可。課題の登録は1日8件まで |
| 嘘の「休講」で全員に通知を飛ばす | 投稿しただけでは通知しない。投稿者のほかに1人が「確認」して初めて全員に通知。「違う」が2人以上かつ確認より多いと折りたたむ |
| 出席コードの共有 | 数字・英字だけの短い連絡や「コード」と数字の組み合わせは投稿できない |
| 依頼を引き受けて何もしない（取り逃げ） | 依頼者は希望期限後に取り消せて、預けたぺいが戻る。相手のプロフィールに「途中放棄」が記録される。同時に引き受けられるのは3件まで |
| 終わったのに払わない（払い逃げ） | 報酬は依頼を出した時点で預かる。完了報告から72時間、依頼者が何もしなければ自動で支払う |
| 終わっていないのに完了と言い張る | 依頼者は「問題があった」を押せる。報酬は預かったまま |
| 掲載期限切れの依頼の放置 | 自動で取り下げて返金 |
| 誤送金・なりすましへの送金 | 送る前に相手のアイコン・名前・学籍番号の確認画面を出す。1日10回・3,000ぺいまで。名前の変更は30日に1回、悪口は名前に使えない |
| 学籍番号からの名簿づくり | 送金の検索は学籍番号4桁以上の前方一致のみ |
| 特定の人からの嫌がらせ | ブロックすると、相手の書き込み・依頼・提出の共有が見えなくなり、送金・依頼のやりとりもできなくなる（相手からも） |
| 荒らしの投稿 | 「…」から通報。3人から通報されると自動で非表示（本人には見えていて、注意書きが出る） |
| 何度も荒らす人 | 非表示にされた投稿・沈んだ連絡が合わせて3つ、または本人への通報が5人から来たら、書き込み・依頼・送金・課題登録を制限 |
| 通報の悪用 | 同じ人の重複通報は数えない。通報は1日15件まで。1人や2人の通報では何も起きない |
| 取引相手の見極め | 依頼の一覧・詳細・プロフィールに、取引の完了数・👍・👎・途中放棄の数を表示 |

数値は [src/lib/moderation.ts](src/lib/moderation.ts) の `LIMITS` と `MOD` で変えられます。

デモデータには荒らしの例として「ななし」さん（学籍番号 4624009）がいます。通報で隠れた書き込みや途中放棄の記録があるので、見比べてみてください。

## 本番に向けて残っていること

- **荒らし対策はサーバー側でも必要**：いまのチェックはすべてブラウザ側なので、本番では同じ判定・回数制限・預かり口座の処理をサーバーで行う必要があります。通報が集まった投稿を運営が確認して、制限の解除や問題が起きた依頼の判断をする管理画面も必要です

- **LINE ログイン**：いまはモックです。LINE Login（LIFF）で表示名とアイコンを受け取る処理に差し替えます。友だち追加に使う LINE ID は、LINE ログインでは取れないので本人に入力してもらう形です
- **サーバーとデータベース**：いまは全データがブラウザ内にあり、他の人とは共有されません。Supabase などに移して、本人確認（学籍番号の確認）と権限チェックをサーバー側で行う必要があります
- **通知**：いまはアプリを開いているあいだだけ届きます。閉じていても届けるには Web Push（サービスワーカー）か LINE 公式アカウントのメッセージが必要です
- **ぺい**：送金や残高の計算をサーバー側に移し、不正な書き換えを防ぐ必要があります
